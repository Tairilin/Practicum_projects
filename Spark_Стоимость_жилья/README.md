# 📃 Описание проекта

В данном проекте необходимо обучить модель линейной регрессии на данных о жилье в Калифорнии в 1990 году. На основе указанных данных нужно предсказать медианную стоимость дома в жилом массиве — 'median_house_value'.

# 🎯 Задачи проекта:

- обучить две модели линейной регресии (одна - со всеми признаками, другая - только с числовыми);
- сделать предсказания на тестовой выборке;
- оценить качество моделей с помощью метрик RMSE, MAE и R2.

# 📦 Описание данных

В датасете содержатся данные о жилых массивах и их населении в Калифорнии за 1990 год.

# 🏆 Результат:

В рамках данной работы я:
- Инициализировала локальную Spark-сессию;
- Прочитала DataFrame и кратко взглянули на его содержимое;
- Провела предобработку заключенных в нем данных, используя методы pySpark, а именно:
  - Исправила типы данных на более подходящие;
  - Исследовала данные на наличие пропусков;
  - Проверила данные на наличие дубликатов, которые не обнаружили;
  - Разбила данные данные на обучающую и тестовую выборки;
  - Заполнила пропуски медианой;
  - Преобразовала колонку с категориальными значениями;
  - Провела стандартизацию количественных признаков.

Затем я построила две модели линейной регрессии на разных наборах данных:

- используя все данные из файла;
- используя только числовые переменные, исключив категориальные.

По итогу обучения моделей я выяснила, что обе модели не обладают высокой точностью (возможно, моделям не хватает признаков, или признаки мало коррелируют с целевым, или выборка с данными слишком мало для получения качественных моделей). Но согласно всем трем метрикам RMSE, MAE и R2 точнее работает первая модель, использующая все данные из файла.

Использование или неиспользование пайплайна для работы с моделями не влияет на их метрики.
