# 📃 Описание проекта

В данном проекте мне было необходимо создать модель, которая будет классифицировать комментарии на позитивные и негативные.

## 🎯 Цели проекта:

Постройте модель со значением метрики качества F1 не меньше 0.75. 

## 📦 Описание данных

Файл `toxic_comments.csv` содержит комментарии и их метки.

## 🏆 Выводы:

- В ходе проекта я изучила данные и очистила их для дальнейшего преобразования.
- Обучила одну базовую и четыре основные модели, используя несколько вариантов подготовки теста (TF-IDF и мешок слов).
  Лучшей моделью стала Logistic_Regression с подготовкой с момощью метода TF-IDF. Ее метрика f1 на тестовых данных составила 0.7531, что удовлетворяет требованию заказчика.
- Провела анализ предсказаний лучшей модели, который показал, что: 
  - В целом модель хорошо разделяет классы.
  - Модель хорошо предсказывает отрицательный класс.
  - Модель правильно идентифицирует большинство истинноположительных случаев. При этом, когда модель уверенна в положительном классе, она обычно права.
  - Чтобы не упускать положительные случаи, мы можем изменить порог (увеличив полноту ценой снижения точности).
 
# 🛠 Инструменты
`python`, `pandas`,  `numpy`, визуализация данных с помощью  `matplotlib` и `seaborn`, `tqdm`, работа с текстами: `nltk`, `re`; `sklearn` (`TF-IDF` и `мешок слов`, базовая модель `DummyClassifier`, логистическая регрессия LogisticRegression, метрики и матрица ошибок, пайплайны для подготовки данных и перебора гиперпараметров в целях определения лучшей модели), `LGBMClassifier`.
