# 📃 Описание проекта

В данном проекте я выполняла роль аналитика сервиса такси. Для привлечения большего количества водителей в период пиковой нагрузки было необходимо построить модель, чтобы предсказывать количество заказов на следующий час.

## 🎯 Цели проекта:

Значение метрики RMSE на тестовой выборке должно быть не больше 48.

## 📦 Описание данных

Файл `taxi.csv` содержит исторические данные о заказах такси в аэропортах.

## 🏆 Выводы:

При выполнении проекта я
- Изучила данные;
- Создала новые признаки для решения задачи;
- Обучила одну базовая и четыре основые модели;
- Провела анализ важности признаков лучшей из моделей.

Лучшей из обученных моделей стала DecisionTreeRegressor c RMSE на кросс-валидации 27.51 и 43.16 на тестовых данных. Однако она имеет признаки переобучения, поэтому может потребоваться ее доработка. Самыми главными признаками для модели стали lag_24, lag_1.

# 🛠 Инструменты
`python`, `pandas`,  `numpy`, визуализация данных с помощью  `matplotlib` и `seaborn`, работа с временными рядами с помощью `statsmodels`, `sklearn` (базовая модель `DummyRegressor`, линейная регрессия LinearRegression, деревянные модели `DecisionTreeRegressor` и `RandomForestRegressor`, масштабирование данных, перебор гиперпараметров в целях определения лучшей модели), `LGBMRegressor`, анализ важности признаков при помощи `shap`.
