# 📃 Описание проекта

В нашу выполняющую на заказ проекты по машинному обучению IT-компании обратился фермер, владелец молочного хозяйства «Вольный луг». Он хочет купить новых коров, чтобы расширить поголовье имеющегося стада. Для чего фермер заключил контракт с ассоциацией пастбищ «ЭкоФерма».

Условия контракта позволяют заказчику очень тщательно отобрать коров. Он определяет качество молока по строгой методике, и при этом ему нужно выполнять свой план развития молочного хозяйства. Заказчик хочет, чтобы каждая новая корова давала не менее 6000 килограммов молока в год, а её надой был вкусным (строго по его критериям, не хуже).

«ЭкоФерма» готова предоставить подробные данные о своих коровах.

## 🎯 Цели проекта:

- Разработать модель машинного обучения, которая поможет заказчику управлять рисками и принимать объективное решение о покупке.
- Рекомендовать заказчику к покупке определенных коров из предложенных продавцом.

## 📦 Описание данных

Я буду работать с тремя датасетами:
- `'ferma_main.csv'`
- `'ferma_dad.csv'`
- `'cow_buy.csv'`

Файл `'ferma_main.csv'` содержит данные о стаде фермера на текущий момент.

## 🏆 Выводы:

Обученные на основании данных стада заказчика модели показали, что почти три четверти коров (14 из 20) с высокой долей вероятности будут давать более 6000 кг молока в год. Однако 100% попадания в категорию вкусное не показала ни одна корова, так как с учетом их неизменяемых параметров и будущих изменяемых (за исключением пастбищ, которые, возможно, будут такими же) их вероятность получения вкусного молока оказывается ниже того порога классификации вероятностей, чтобы гарантированно исключить покупку коровы с невкусным молоком.

Ввиду этого мы можем лишь минимизировать риски покупки коровы с невкусным молоком, выбрав тех, у кого вероятность вкусного молока выше при как можно большем удое. Таким критерим отвечают коровы с индексом 0, 6 и 12.

Также предложены следующие рекомендации:
- Установить иные критерии, которые могут влиять на вкус молока. Например, содержание определенных макроэлементов в корме коровы, виды растений на пригодных к выпасу территориях, состояние здоровья коровы.
- В случае необходимости пересмотреть рацион коров с невкусным молоком, ориентируясь на тот, что сочтет вкусным модель с измененным порогом при применении ее к имеющемуся стаду.
- Запросить новую выборку коров для покупки с учетом установленных закономерностей.
