# 📃 Описание проекта

В данном проекте я выполняла роль аналитика для популярного сервиса аренды самокатов. Было необходимо проанализировать переданные данные и проверить некоторые гипотезы, которые могут помочь бизнесу вырасти.

## 🎯 Цели проекта:

 - Изучить информацию о пользователях и их поездках, в том числе в зависимости от наличия и отсутствия подписки.
 - Проверить предложенные продакт-менеджерами гипотезы для последующего проведения акций, направленных на увеличение количества пользователей с подпиской.

## 📦 Описание данных

В полученных данных есть информация о пользователях ('users_go.csv'), их поездках ('rides_go.csv') и подписках ('subscriptions_go.csv').

## 🏆 Выводы:

В рамках данной работы я:
- Подготовита данные для анализа и изучила их.
- Составила совокупный портрет среднестатистического пользователя.
- Проверила предоставленные гипотезы.
- Решила дополнительно требуемые статистические задачи. 
- Составила рекомендации для заказчика.

# 🛠 Инструменты
 `python`, `pandas`,  `numpy`, визуализация данных с помощью  `matplotlib` и `seaborn`, `math` для дополнительных математических действий, `scipy` (scipy.stats) для проверки статистических гипотез и решения дополнительных задач)
